## Admin authentication

The admin workspace is protected by a signed, HTTP-only session cookie.

Required server environment variables:

```env
CVUP_ADMIN_EMAIL=your-admin-email@example.com
CVUP_ADMIN_PASSWORD=use-a-strong-private-password
CVUP_ADMIN_SESSION_SECRET=use-a-random-secret-with-at-least-32-characters
```

Do not commit real values. Keep them in `.env.local` locally and configure the same variables in the production deployment environment.

Protected routes:
- `/admin/*`
- `/api/admin/*`

Public auth routes:
- `/admin/login`
- `/api/admin/auth/login`
- `/api/admin/auth/logout`
